# Spring Boot 3 - Quartz Scheduler Implementation Example

самый базовый набор для quartz 
Задачи сохраняем в postgresql
на данный момент - нет реализована возможность возобновить задачу  
 
This is a simple example of how to implement Quartz Scheduler in a Spring Boot application.
This example will show you how to schedule a job.
Postgresql as a quartz storage

### Install dependencies
```bash
mvn clean install
```

### Run project
```bash
mvn spring-boot:run 
```

### Build project
```bash
mvn clean package
```
